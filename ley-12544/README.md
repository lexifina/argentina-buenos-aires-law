# Ley 12.544: VERIFICACIÓN TÉCNICA VEHICULAR (VTV). SUSPENDE POR 150 DÍAS TODA ACTUACIÓN PARA LA APLICACIÓN DE PENAS DERIVADAS DE ACTA DE INFRACCIÓN POR FALTA DE VERIFICACIÓN Y QUE FUERA CONFECCIONADA POR RADARES. CONDONA MULTAS Y PROHIBE LA UTILIZACIÓN Y EMPLAZA
