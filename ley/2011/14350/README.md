# Ley 14.350: ESTABLECE QUE LAS EMPRESAS PRESTADORAS DE SERVICIOS PúBLICOS, CONCESIONARIAS PRIVADAS Y DE CAPITAL MIXTO, DEBERáN EMITIR Y ENTREGAR POR EL MISMO MEDIO QUE LAS FACTURAS, UN CERTIFICADO DE INEXISTENCIA DE DEUDA A TODOS LOS USUARIOS QUE NO REGISTREN DEUDA.-
