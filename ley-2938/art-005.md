ARTÍCULO 5.- Por este camino no podrán transitar sino vehículos dotados de elásticos suficientes para resistir el peso para que fueron construídos, no pudiendo exceder la carga de cada vehículo de mil quinientos kilos por eje, debiendo las llantas de las ruedas tener un ancho no menor de 0 m. 15 cuando se trate de carros construídos para resistir un peso mayor de mil kilos.
Quedan facultadas las Municipalidades de Avellaneda y Lomas de Zamora, para vigilar y hacer cumplir esta disposición.
